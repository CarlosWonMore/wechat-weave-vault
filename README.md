# WeaveVault for WeChat

把微信 4.0 全量聊天记录编织成**可检索、可深挖、可维护**的 Obsidian 个人知识库。

- SkillHub：<https://skillhub.cn/skills/wechat-weave-vault>
- 许可：MIT-0
- 支持平台：Windows / macOS / Linux
